## Scott Lilly

I have been paid to write software for more than 40 years, which is long enough to have shipped
in languages that no longer exist and to have stopped believing any of this gets easier.

These days the work splits three ways: small games I intend to sell, a multi-tenant SaaS, and the
developer tools that make the first two go faster. Most of what is public here is a fourth thing,
and probably the most useful: C# tutorials that a lot of people learned from.

### Learn C# here

These are archived and read-only, and they are still the best reason to visit this profile.
Between them they have been forked 99 times by people working through the lessons, which is a
better number than the star count.

| Repo | Lessons |
|---|---|
| [SOSCSRPG](https://github.com/ScottLilly/SOSCSRPG) | Build a complete WPF role-playing game from an empty solution. The long one. [Lessons](https://soscsrpg.com/) |
| [CSharpDesignPatterns](https://github.com/ScottLilly/CSharpDesignPatterns) | Worked C# examples of the classic patterns, one project each. [Write-ups](https://scottlilly.com/c-design-patterns/) |
| [SuperAdventure](https://github.com/ScottLilly/SuperAdventure) | The original "Learn C# by building a simple RPG" guide, from 2014. [Lessons](https://scottlilly.com/learn-c-by-building-a-simple-rpg-index) |
| [FluentInterfaceCreator](https://github.com/ScottLilly/FluentInterfaceCreator) | Generates fluent interface files, and demonstrates why you would want one. [Notes](https://scottlilly.com/fluent-interface-creator/) |

### Currently building

- **MogriChess**, a chess variant where a capturing piece absorbs the movement abilities of the
  piece it takes. The name comes from the Calvin and Hobbes
  [Transmogrifier](https://calvinandhobbes.fandom.com/wiki/Transmogrifier). The
  [public repo](https://github.com/ScottLilly/MogriChess) is the original WPF version; the one I
  am finishing now is a rewrite aimed at Steam.
- **A multi-tenant asset-tracking SaaS**, which is where the unglamorous work goes: tenancy, audit
  trails, import and export.
- **Developer tooling**, some of it public.
  [SolutionScribe](https://github.com/ScottLilly/SolutionScribe) generates the LICENSE, README and
  other boilerplate documents for a solution.
